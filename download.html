How to install

  1. Download the APK. If using a GitHub build artifact, extract the APK from its ZIP first.
  2. Open the APK on your Android phone and follow Android’s installation prompt.
  3. Sign in with the same account as the Footy website.

Public APK downloads do not require a GitHub account. Build artifacts require GitHub sign-in. Debug previews may require uninstalling a previous preview first; guest-only data is removed on uninstall. Signed-in profiles and follows stay in your account.

The app checks for signed releases daily. Android may delay background checks to save battery. Updates are installed only when you choose.
