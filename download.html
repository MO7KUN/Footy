Install on Windows

  1. Download and run Footy-Windows-Setup.exe.
  2. Choose your installation folder and shortcuts.
  3. Open Footy from your desktop or Start menu and sign in with your existing account.

Signed-in follows and preferences sync with the website. Guest follows and sign-in sessions are stored separately on each device. Notifications work while Footy is open. For desktop updates, choose Footy → Downloads and updates and install the latest version. You can uninstall Footy from Windows Settings → Apps.

Footy for Android

View Android downloads ↗Requires Android 7 or newer and an up-to-date Android System WebView. Only install Footy from this repository.

Install on Android

  1. Download the APK. If using a GitHub build artifact, extract the APK from its ZIP first.
  2. Open the APK on your Android phone and follow Android’s installation prompt.
  3. Sign in with the same account as the Footy website.

Public APK downloads do not require a GitHub account. Build artifacts require GitHub sign-in. The production app installs alongside your old preview. Keep the preview until you have checked your data in the new app.

Move from a preview safely

  1. Keep the old preview installed. Sign in there with your Footy account.
  2. Open Profile / Football and choose Import club & league follows from this browser to save guest follows to your account.
  3. Install Footy, sign in with the same account, and check your profile, follows and preferences.
  4. Enable notifications in the new app and copy your custom AI endpoint from the old Settings if you used one. Local settings do not transfer automatically.

Removing the preview deletes its local data. Keep it until you have verified everything you need.

The app checks for signed releases daily. Android may delay background checks to save battery. In version 1.0.1 and later, open Settings / App updates, check for updates, then choose Download and install. Allow installation from Footy when Android asks, return to Footy and tap the button again. Android confirms every installation. Version 1.0.0 users need to install this release once from this page to gain the in-app updater.
